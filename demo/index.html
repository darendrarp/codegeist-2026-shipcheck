Is this release ready to ship?

ShipCheck scores a Jira release 0–100 from live work items, linked Bitbucket pull requests and Confluence docs — then names the blockers, finds their owners in the Teamwork Graph, and drafts the release notes. No LLM in the scoring: every point is explainable. Try it: change an issue status or approve a PR and watch the score move.

Interactive demo — runs the real scoring engine from the Forge app (src/engine.js) on sample data. The full app also ships a Rovo agent, MCP tools, a Jira dashboard, and hourly re-scoring.
